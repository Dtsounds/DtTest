📖 How to Install Your Addon
Quick method: Double-clicking the downloaded .mcaddon file will automatically import it into Minecraft Bedrock on Windows and Android.
🪟 Windows
📱 Android
🍎 iOS
🌍 Applying to World
1
Click "Export .mcaddon" above
Download the .mcaddon file to your computer.
2
Double-click the file (easiest)
Windows will automatically open Minecraft and import the addon. Skip to Step 5.
3
Manual install (if double-click doesn't work)
Rename the file extension from .mcaddon to .zip, then extract it. Copy the _BP folder to:
%localappdata%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang\behavior_packs\
Copy the _RP folder to:
%localappdata%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang\resource_packs\
4
Add textures (if needed)
Placeholder textures are generated automatically. To use custom textures, replace the .png files inside the _RP/textures/ folders with your 16×16 pixel art images.
5
Launch Minecraft and apply to a world
Open Minecraft → Create or Edit a World → Resource Packs / Behavior Packs → Activate your addon → Play!
1
Export and transfer the file
Download the .mcaddon file on your PC and transfer to your Android device via USB, cloud storage, or email.
2
Open the file with Minecraft
Tap the .mcaddon file in your file manager. Select "Open with Minecraft". The game will import it automatically.
3
Manual path (alternative)
/storage/emulated/0/games/com.mojang/behavior_packs/
/storage/emulated/0/games/com.mojang/resource_packs/
1
Get the file on your device
AirDrop, iCloud Drive, or any other method to get the .mcaddon file to your iPhone/iPad.
2
Open with Minecraft
In Files app, tap and hold the .mcaddon file → Share → Open with Minecraft. The addon will be imported.
3
Apply to a world
Go to world settings and activate both the Behavior Pack and Resource Pack.
1
Open or Create a World
In Minecraft, go to Play → Create New World (or edit an existing one).
2
Activate Behavior Pack
Scroll to "Behavior Packs" in world settings → My Packs → find your addon → tap Activate.
3
Activate Resource Pack
Go to "Resource Packs" → My Packs → find your addon → tap Activate.
4
Note: Experimental Features
Some features may require "Holiday Creator Features" or "Beta APIs" to be enabled in Experiments. Check the Experiments section in world settings if items or blocks don't appear.
